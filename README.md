# 旋回リバーシ (Orbit Reversi)

一定の手数ごとに盤面の一部が自動で回転する、オセロの変種ゲームです。
ブラウザだけで動きます(ビルド不要。オンライン対戦のときだけ Firebase を読み込みます)。

## 遊び方

- 置けるのは、相手の石を1枚以上返せるマスだけです(通常のオセロと同じ)。
- 設定した手数ごとに、盤の一部が右回り・左回りに旋回します。
- 次に回る場所と向きは、盤上の色と矢印で予告されます(青 → 黄 → 赤 の順で旋回が近づきます)。

## 設定できること

| 項目 | 選択肢 |
|---|---|
| 対戦形式 | 対人(1台で交代) / AI対戦 / オンライン |
| AIの強さ | よわい / ふつう / つよい / さいきょう |
| 旋回タイプ | リング(外周〜中央の輪) / 4マス / 複合 |
| 旋回箇所 | 1〜4か所 |
| 旋回ターン | 1〜5手ごと |

## オンライン対戦

1. 対戦形式で「オンライン」を選び、手番と旋回の設定を決めて「部屋を作る」を押す。
2. 表示された部屋コード(5文字)か招待URLを相手に送る。
3. 相手は招待URLを開くか、「部屋に参加」にコードを入れて「参加」を押す。そろった時点で対局が始まります。

通信には Firebase Realtime Database を使います(匿名ログイン)。データベースのルールは `database.rules.json` の内容を Firebase の画面で設定します。

## ファイル構成

- `index.html` … ゲーム本体(HTML・CSS・JavaScript)
- `online.js` … オンライン対戦の通信処理(部屋の作成・参加、着手の送受信)
- `database.rules.json` … Firebase Realtime Database のアクセスルール
