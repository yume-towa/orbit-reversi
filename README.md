# 旋回リバーシ (Orbit Reversi)

一定の手数ごとに盤面の一部が自動で回転する、オセロの変種ゲームです。
ブラウザだけで動きます(HTML 1ファイル、ライブラリ不要)。

## 遊び方

- 置けるのは、相手の石を1枚以上返せるマスだけです(通常のオセロと同じ)。
- 設定した手数ごとに、盤の一部が右回り・左回りに旋回します。
- 次に回る場所と向きは、盤上の色と矢印で予告されます(青 → 黄 → 赤 の順で旋回が近づきます)。

## 設定できること

| 項目 | 選択肢 |
|---|---|
| 対戦形式 | 対人(1台で交代) / AI対戦 |
| AIの強さ | よわい / ふつう / つよい / さいきょう |
| 旋回タイプ | リング(外周〜中央の輪) / 4マス / 複合 |
| 旋回箇所 | 1〜4か所 |
| 旋回ターン | 1〜5手ごと |
